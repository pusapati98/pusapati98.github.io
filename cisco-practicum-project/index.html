Cisco Practicum Project

Product Returns • Process Improvement • Automation — Data Science Practicum with Cisco

Overview

This practicum project with Cisco focused on analyzing large-scale Return Merchandise Authorization (RMA) data to uncover patterns in product failures, resolution bottlenecks, and opportunities for automation. We examined issue frequencies, resolution times, and repair alignment scores across multiple product families and customer segments.

  • Key goals: identify failure hotspots, reduce resolution delays, and recommend automation candidates.
  • Tech: Python, SQL, Tableau, Excel, advanced data visualization & analysis.
